# Image2D3 Project

This project reconstructs a historical visualization image using **D3.js**, aiming for **pixel-aligned** output:
- **Style must match** the reference (fonts, colors, strokes, layout)
- **Data must be correct** (derive values from the chart; do not invent)

## Key inputs

- `public/reference.png`: the reference image to match
- `original_visualization/reference.png`: same image (kept for provenance)
- `transform-plan.md`: plan generated by `prepare_image2d3_project.py` (if enabled)

## Where to implement

- `src/components/Visualization.tsx` is the only file you need to change for the reconstruction.
  - The SVG uses `viewBox="0 0 width height"` so coordinates are **pixel-like**.
  - Implement everything in SVG (fills, strokes, fonts) for stable rendering.

## Verification loop

- `uv run python render.py`
  - Starts `bun dev`, screenshots `#reconstruction-container`, saves `reconstruction.png`

- `uv run python compare.py`
  - Computes pixel diff between `public/reference.png` and `reconstruction.png`
  - Writes `diff.png` and prints MAE/RMSE

Use this loop to iterate until the diff is minimal.

## Technical requirements

- Use `bun` for JS.
- Use `uv` for Python.
